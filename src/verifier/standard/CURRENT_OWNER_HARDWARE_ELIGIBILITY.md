# Current OWNER declared hardware-ownership eligibility

Verifier Standard (VSTD); Secure Hash Algorithm 256-bit (SHA-256); Simulation
(SIM); JavaScript Object Notation (JSON). This contract transports the
existing [namespace accountability contract](NAMESPACE_OBJECTS.md), preserving
its exact bounded meaning. It registers current `OWNER-3.1` under
`verifier-current-object-obligations-1`; it does not reinterpret legacy
`OWNER-3.1` computational verdict independence. The current version is selected explicitly; matching legacy spelling supplies no evidence.

The consumer independently selects the exact OWNER identifier and record digest,
complete collection digest, evidence-byte reference, installed mechanism,
proposition, trust-root labels, checking limits and optional finite isolation
binding. The latter is either null or exactly `sim_id`, `evidence_digest`,
`max_operations` and `max_items`. Evidence contains exactly `schema_version`,
the retained `objects` and `isolation_evidence`, whose required key may be null.
An omitted key is malformed. Evidence supplies no policy
or authoritative isolation binding.

The mechanism reconstructs the exact immutable namespace records, checks typed
composition and calls the existing hardware-ownership assessor. HUMAN may own
declared physical or virtual HARDWARE. AGENT may not own HARDWARE. BOT may own
only virtual HARDWARE inside its own freshly replayed finite isolated SIM,
with the exact SIM, retained isolation evidence, object inventory, resource
identifier and resource kind bindings. A carried isolation PASS is insufficient.

Non-HARDWARE eligibility, unspecified hardware realm, absent BOT isolation
evidence or absent SIM commitments remain UNKNOWN. Demonstrated kind violations,
substitution and resource disagreement remain FAIL. Evidence unavailability and
selected budget exhaustion remain UNKNOWN. No digest by itself resolves support.
Recheck reconstructs the complete certificate byte for byte under separately
supplied consumer selection; a rehashed invented PASS is refused.

Limits count objects, input-traversal operations and items, with a separately
selected composition operation budget and the isolation binding's own SIM
operation/item budgets. These are separate counters. The decoder preflight
bounds nesting to the selected depth (at most 48) and integers to 1,234 decimal
digits; exhaustion is UNKNOWN. Encoded evidence, references, payloads and
certificates count bytes. The wrapper may narrow existing native
bounds; it cannot enlarge or replace them. Certificates retain legal title,
human authenticity, authority, physical host containment, actual enforcement,
whole OWNER statics tier and object-profile conformance as NOT_ESTABLISHED.
The property is one declared eligibility predicate, not acquisition permission,
runtime authorization, legal ownership or full tier coverage.
