record positions and operation limits are dimensionless; byte bounds count encoded
bytes. These predicates describe retained computation, not actual execution.

## External binding and native replay

The independently selected request binds the exact BOT subject, object digest,
complete namespace collection, canonical evidence bytes, native check, proposition,
installed mechanism, external policy and resource limits. A certificate cannot
choose its own acceptance conditions. Reconstruction must be byte-canonical.

The collection is checked against [the current namespace](NAMESPACE_OBJECTS.md).
BOT's direct AGENT, SIM and ENV operands are selected by their actual identifiers.
AGENT's HARNESS, MODEL and ENV operands and SIM's ENV operand are selected in turn.
Typed GRAPH operands are valid structural declarations, but this finite native
mechanism requires one direct record per role and returns UNKNOWN otherwise.

The `verifier-current-bot-checks-evidence-1` input carries four retained native
certificates: `agent_certificate`, `sim_certificate`, `agent_environment_certificate`
and `sim_environment_certificate`. Their subjects and artifacts must equal the
actual selected operands. The agent's nested harness subject and artifact must
equal its selected HARNESS operand. `environment` retains the BOT environment
payload; `agent_model` retains its AGENT's MODEL payload. These two context bindings
do not certify environment behavior or model correctness.

The native mechanism replays AGENT to legacy native check depth 5, SIM to depth 4,
and both ENV certificates to depth 2, with the nested HARNESS reached through AGENT.
Replay uses current externally selected trust-root labels, numerical tolerance
ceiling and resource limits, no witness keys, and one shared recursive operation
budget. `max_tolerance` defaults to zero and must lie between zero and 0.0001,
preserving the native policy's supported ceiling. Boolean, nonnumeric, negative
and nonfinite values are refused. This is an absolute tolerance in each compared
retained scalar's units; no physical dimensional model is inferred. A child requesting
more tolerance than the current policy admits remains UNKNOWN, even if its historical
policy allowed it. The native source/specification/runtime descriptor and direct current
contract dependencies bind the policy. Historical child-policy reproduction remains
`NOT_ESTABLISHED`; a retained historical policy digest is not current authority.

BOT, AGENT and SIM environments need not be equal. Distinct retained environment
inventories are a finite declaration check, not physical isolation or proof of
simulation effect confinement. A fused declaration returns UNKNOWN for containment.

## Falsification and limits

Native selection rejects unsupported values before evidence access. Alignment
requires strictly increasing valid record positions and explicit exogenous
transitions; attributing no transition to the agent remains UNKNOWN. Observation
checks the initial record's channel against the agent ceiling, as well as later
attributed records. Out-of-ceiling observations remain UNKNOWN; conflicting
retained projections or actions are refuted. Retained invocation correspondence
does not authenticate who actually invoked a tool or establish causal control.

Missing evidence, unsupported native composition and exhausted selected bounds
remain UNKNOWN. Substituted subjects, records or carried results cannot establish
PASS. Rechecking rebuilds the exact canonical certificate under the independently
selected request and policy. Canonical evidence cannot be redacted and still claim
to be the same reproducible certificate.

A mebibyte (MiB) is 1,048,576 bytes. Bounds are 256 objects, 4,096 items, 100,000 shared
native operations, 100,000 composition operations, 4 MiB evidence/payload/reference
bounds and 8 MiB certificate bytes. Caller-selected lower limits remain binding.

No result establishes actual execution, authentic recording, live model behavior,
physical containment, complete historical coverage, authenticated authority,
complete tier conformance or polished-artifact issuance. Public command selection
does not establish public availability of every private witness.
