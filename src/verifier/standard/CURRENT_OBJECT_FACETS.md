An externally selected request binds the exact proposition-registration digest, current coordinate and semantic version, identifier, kind, complete record digest, canonical payload and operand-map digests, address digest, one content-addressed evidence reference, policy digest and finite checker limits. The request formatter snapshots exact built-in namespace fields and charges the selected payload, operation and canonical reference-byte bounds before full serialization.
