# Current EVENT declared prerequisite and payload check

Status: experimental, versioned current-object objective. Verifier Standard
(VSTD) defines the claim language; the Python module is one reference checker.
JavaScript Object Notation (JSON) gives canonical retained bytes and Secure Hash
Algorithm 256-bit (SHA-256) names commitments. Sequence numbers, event counts,
edges and operation budgets are dimensionless. Evidence and certificate bounds
are measured in bytes.

The pair `verifier-current-object-obligations-1` / `EVENT-3.1` selects one
bounded statics proposition. Current `EVENT-1.1` checks declared typed TIME,
SPACE and meaning operands. This new objective also replays selected EVENT
payloads and declared prerequisites, but it does not establish an actual
historical occurrence, physical causality or the whole EVENT statics tier.

The externally selected exact EVENT namespace record occurs once in a selected
finite typed collection, and every EVENT in its reachable declared prerequisite
cone has a retained canonical JSON payload object matching its selected
`payload_digest`. Each EVENT record in that cone has exactly `scope`,
`sequence`, `prerequisites` and `payload_digest`; the scope is
`retained-declared-prerequisites`. A sequence is a nonnegative plain integer no
greater than 2^53-1. Prerequisites are a finite list of unique bounded EVENT
object identifiers. Each named parent must occur in the selected collection
and have a strictly lower sequence value. The checker traverses the cone
iteratively and requires the retained payload map to contain exactly that cone.
Unrelated EVENT records may exist in the collection, but their semantic
payloads are outside this selected claim. Sequence gaps are allowed.

`PASS` means the finite retained declared relation and payload commitments
reproduced. `FAIL` means the selected bytes contradict the proposition,
including a missing or non-EVENT parent record, a nonpreceding sequence,
duplicate prerequisite, changed payload, or unrelated extra retained payload.
`UNKNOWN` means required retained bytes or selected checking capacity is
unavailable. Malformed or substituted requests, policies and certificates are
rejected before a computational verdict. Exact retained bytes and the selected
policy are rerun; source or specification changes invalidate the mechanism
digest. Trust-root labels do not authenticate an observer.

The certificate carries the retained payload objects. Do not put confidential
inputs in a public certificate without separate disclosure authority. TIME,
SPACE and meaning operand truth, occurrence authenticity, actual causality,
privacy, consent, governance, security, global event-log closure and whole
EVENT tier conformance remain `NOT_ESTABLISHED`. This check authorizes no
scheduling, spending or publication.

The installed descriptor also binds `retained_selection.py`, the shared plain-value
request and policy capture helper. Native evaluation remains specific to this
objective; shared selection infrastructure does not establish its proposition.
