# Current retained model checks

Model reproducibility specification (MODEL); Verifier Standard (VSTD); JavaScript
Object Notation (JSON); dataset integrity and lineage (DATA); computational model
architecture (ARCH); benchmark specification graph (BENCH); training run specification
(TRAIN); verifiable execution environment (ENV); rectified linear unit (ReLU). EVENT,
TIME, SPACE, HARDWARE, VERIFIER and OBJECT are namespace kind names. Model values
carry their selected contract units; indices and resource counts are dimensionless.

These experimental propositions use `verifier-current-object-obligations-1`.
Each independent request binds the exact subject, collection, evidence, native
check, proposition, installed mechanism, policy and finite limits. Every retained
namespace record reconstructs exactly and passes typed finite composition.

| Current coordinate | Native check | Exact bounded proposition |
|---|---|---|
| MODEL-1.5 | artifacts | Rehash architecture, weights and dependencies; bind weights to the final declared training checkpoint. |
| MODEL-1.2 | tensors | Check complete dense tensor shapes and architecture compatibility. |
| MODEL-2.1 | inference | Execute every selected input and compare its retained output within the selected tolerance. |
| MODEL-4.2 | evaluation | Recompute the selected complete-set metric and compare its report and exact numeric thresholds. |
| MODEL-4.4 | challenges | Execute every selected finite probe against its bound output predicate. |

Current MODEL-1.1 remains typed structural facets; legacy tensor inventory does
not overwrite it. These separately versioned predicates include the required
native work but do not waive legacy prerequisites, register neighboring objectives,
or establish whole-tier coverage. Historical certificates retain their meanings.

The MODEL payload is its native artifact. Evidence has exactly schema_version,
objects and inputs. Inputs admit architecture, weights, dependencies, samples
and metric_value. Each non-event model role selects one direct record of its
declared kind; graph replacements or multiple operands remain UNKNOWN here.
The architecture input equals the ARCH payload. Dependencies have exactly training,
checkpoint, environment and hardware: training is the selected TRAIN payload,
environment and hardware are the selected ENV and HARDWARE payloads. The retained
checkpoint has exactly weights and optimizer_state; its complete digest must equal
the final checkpoint_digests entry in TRAIN, and its weights must equal the model
weights. TRAIN must select the same ARCH with the same architecture payload.
This checks the declared checkpoint relationship, not training arithmetic,
historical execution, environment correctness or physical hardware authenticity.
Those operands require their own selected native certificates for stronger claims.

DATA contains exactly samples, bound to the model samples_digest. BENCH contains
exactly metric, metric_bounds, tolerance and challenges from the selected MODEL
payload. It selects the same DATA and one direct VERIFIER with exactly this
contract's mechanism_id and installed mechanism_digest. This selection does not
establish empirical population validity or general checker correctness.

Each direct EVENT contains index and sample. Its TIME has exactly that index;
SPACE has exactly scope=retained-model-evaluation; OBJECT meaning has exactly
operation=model-inference, weights_digest and architecture_digest. Each role
selects one direct record. Event indices must be contiguous from zero and their
ordered samples must equal DATA. Supplied native samples must equal that same set.
Retained event declarations do not establish physical execution or observation.

The checker uses ordered Python binary64 dense linear/ReLU arithmetic. Metrics
are mean squared error, mean absolute error or argmax accuracy; tied maxima use
the first output index. Regression metrics average over sample-output scalars;
accuracy averages over samples. The independently selected bounds retain exact
parsed numeric values; float conversion cannot hide a threshold violation.
Finite probes use bounded native expressions. They do not prove universal behavior,
generalization, accelerator equivalence, sampling entropy or deployed correctness.

Defaults admit 256 objects, 4096 items per container, 100000 native and composition
operations, 4 MiB evidence/payload/reference bounds and 8 MiB certificates
(MiB = 1048576 bytes). Namespace records also retain their own byte ceiling.
Evidence traversal is charged before native work. Missing support, unsupported
semantics and exhausted bounds remain UNKNOWN; contradictions are FAIL. Recheck
rebuilds the whole canonical certificate and rejects rehashed result promotion.

The installed commitment covers this contract, native model and numerical code,
common primitives, namespace, receipt, certificate and evidence machinery, and
this specification. Changed dependencies invalidate selected policies. Public
replay uses `vstd current-object check` with explicit version, objective, represented
kind, request and policy. Full profiles, authority, public checkability and
polished-artifact issuance remain unestablished.
