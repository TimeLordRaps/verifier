# Current retained agent checks

Agent trajectory (AGENT); agent harness (HARNESS); model reproducibility
specification (MODEL); verifiable execution environment (ENV); Verifier Standard
(VSTD); JavaScript Object Notation (JSON); Secure Hash Algorithm 256-bit (SHA-256).
Counts and positions are dimensionless; artifact bounds count encoded bytes.

These experimental propositions use `verifier-current-object-obligations-1`.
An independent request selects the subject, exact collection, evidence, native
check, proposition, installed mechanism, external policy and finite limits.
Every namespace record reconstructs exactly and passes finite typed composition.

| Current coordinate | Native check | Bounded proposition |
|---|---|---|
| AGENT-1.8 | harness | Replay the selected retained harness certificate and derive the required observation ceiling under current external policy. |
| AGENT-2.1 | trajectory | Check contiguous integer decision positions and each decision's retained record reference inside that ceiling. |
| AGENT-2.3 | actions | Bind distinct declared actions to exactly one matching retained tool invocation each. |
| AGENT-4.1 | outcomes | Compare the complete retained outcome inventory with its selected contract using exact canonical value types. |
| AGENT-4.3 | claims | Check unique claim identifiers, distinct retained support and exact support-channel correspondence inside the ceiling. |

Current AGENT-1.1 remains typed structural facets. Harness binding uses 1.8,
preserving the historical facet coordinates 1.1 through 1.7. These versioned
predicates do not migrate historical verdicts, waive legacy prerequisites or
establish complete objectives or whole tiers.

The selected AGENT record has one direct MODEL, HARNESS and ENV operand. The
complete records and their collection are externally bound. Retained model and
environment payloads must exactly equal those selected operands. They are declared
context; these checks do not run the model, establish its correctness or equate
the model's own environment with the agent's environment.

Evidence contains exactly schema_version, objects and inputs. Inputs admit
harness_certificate, steps, actions, outcomes, model and environment. The native
harness certificate uses `verifier-domain-certification-1`; its exact subject
identifier and artifact payload must equal the selected HARNESS operand.
The agent's harness_subject_id and harness_certificate_digest bind the same child.
Native recursive checking validates the child's request, evidence, mechanism,
specification, result and required five-check depth. A claimed successful child
is not sufficient: its actual native mechanisms execute again.

Child replay uses the current external trust-root labels and selected operation,
item and evidence bounds, an empty witness-key set and zero numerical tolerance.
Recursive work shares the parent operation budget. The child's historical policy
digest remains retained but is not admitted as the current policy; historical
child-policy reproduction remains NOT_ESTABLISHED. The result reports this limit.

Required observation channels must be instrumented in the replayed harness.
Declared gaps and unobserved channels produce UNKNOWN. Positions in retained
decisions are plain integers contiguous from zero; Boolean and floating equality
cannot substitute. Each decision references an existing record inside the selected
ceiling. The decision text is a retained declaration, not recovered deliberation
or proof that an observation caused a decision.

Each selected action is a tool-name/record-position pair bound to exactly one
retained invocation. Duplicate declared actions and ambiguous duplicate witnesses
are refused. An empty declared action list does not prove no actual action occurred.
Outcome equality preserves canonical scalar types even inside nested records.
Claims have unique identifiers, distinct support indices and distinct channel
names equal to the supporting records' channel set. Valid support references do
not establish statement truth, semantic entailment or completeness of real history.

Native harness replay is required by every selected check. Unselected agent
predicates remain separate: harness binding does not require a trajectory, and
trajectory checking does not establish action, outcome or claim correctness.
Missing selected support and exhausted bounds yield UNKNOWN; contradictions yield
FAIL. Canonical replay rejects substituted external policies, requests and results.

Default ceilings are 256 namespace objects, 4096 items per container, 100000
shared native operations, 100000 composition operations, 4 MiB evidence, payload
and reference bounds, and 8 MiB certificates (MiB = 1048576 bytes). Namespace
records retain their independent size ceiling. Evidence traversal is charged
before native checking; no input loads or executes a tool or model.

Installed dependency binding covers this contract, the agent and common native
primitives, namespace and certificate machinery, this specification, and the
complete native-domain implementation descriptor including its specifications,
runtime and optional cryptography metadata. A changed dependency invalidates the
selected policy. Retained child certificates from another mechanism remain UNKNOWN.
Public selection uses `vstd current-object check`. Actual execution, authenticated
recorders, internal deliberation, authority, complete coverage, public checkability
and polished issuance remain unestablished.
