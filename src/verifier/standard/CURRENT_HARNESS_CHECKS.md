# Current retained harness checks

Agent harness (HARNESS); Verifier Standard (VSTD); JavaScript Object Notation
(JSON); Secure Hash Algorithm 256-bit (SHA-256). Counts and transcript indices
are dimensionless; bounds on retained artifacts measure encoded bytes.

These experimental propositions use `verifier-current-object-obligations-1`.
The independent request binds the subject, complete collection, retained evidence,
selected check, proposition, installed mechanism, policy and resource limits.
All namespace records reconstruct exactly and pass finite typed composition.

| Current coordinate | Native check | Exact bounded proposition |
|---|---|---|
| HARNESS-1.6 | surface | Partition declared observation channels into instrumented channels and named gaps. |
| HARNESS-2.1 | messages | Check every retained record's integer position, role, instrumented channel and payload commitment. |
| HARNESS-2.2 | tools | Pair every retained tool record exactly once with its bound declaration and input/output payload; bind the complete invocation inventory. |
| HARNESS-2.3 | effects | Bind the complete retained effect inventory and check channels, positions and duplicate entries. |
| HARNESS-4.1 | transcript | Recompute both the canonical ordered transcript digest and its pairwise tree commitment. |

Current HARNESS-1.1 remains typed structural facets. Channel partition receives
1.6, leaving historical facet coordinates 1.1 through 1.5 unreinterpreted. The
newly versioned dynamics and closure predicates retain the native work described
here; they neither waive historical prerequisites nor migrate legacy verdicts.
These five predicates do not establish all required objectives or an entire tier.

HARNESS has no required operand roles in the current namespace contract. Its
payload is the native harness artifact. Evidence has exactly schema_version,
objects and inputs; inputs admit records, invocations, effects and declarations.
No model, environment or hardware operand relationship is invented by this route.
Relevant execution, identity and instrument-authenticity claims need separate
evidence and separately selected mechanisms.

The native artifact declares surface, tools, effects, record_count,
transcript_digest and transcript_root as needed by the selected check. Each
surface or effect-channel disposition is instrumented or declared-gap. At least
one observation channel must be instrumented. A retained record has exactly
index, channel, role, payload and payload_digest. Positions are plain integers
contiguous from zero; record_count is a plain integer equal to the retained count.
Boolean and floating-point equality cannot substitute for these integer values.
Roles are user, agent or tool; each record uses an instrumented observation channel.

For tools, declarations is a mapping with exactly the artifact's registered tool
names. Each declaration is a retained object whose name equals its mapping key;
its complete digest equals the tools commitment. Other declaration fields are
opaque protocol metadata. Every tool record must have exactly one invocation;
no duplicate or omitted pairing is admitted. Its tool, declaration_digest, index,
input and output are checked by the native mechanism against the registration
and retained record. The artifact's invocations_digest binds the entire ordered
invocation array. This establishes retained association, not tool functionality.

For effects, effects_digest binds the entire ordered retained effects array.
Every effect has exactly index, channel and payload, names an instrumented effect
channel and an existing plain integer transcript position, and is not duplicated.
An empty selected effect inventory is allowed; it does not prove that no actual
external effects occurred. Effects are not automatically inferred from messages.

For transcript, the canonical digest binds the complete ordered record array.
The tree starts from each record digest; each parent hashes an object with left
and right child digests, duplicating an unpaired final child at every step. Both
commitments are compared exactly. Recomputing these commitments does not establish
real-world history completeness or authenticate the recorder.

Selection is explicit. Surface does not require a transcript, and messages or
transcript do not claim tool-pairing or side-effect correctness. Missing selected
support, unsupported semantics and exhausted limits yield UNKNOWN; contradictions
yield FAIL. Canonical replay rejects substituted requests and forged result claims.

Default ceilings are 256 namespace objects, 4096 items per container, 100000 native
operations, 100000 composition operations, 4 MiB evidence/payload/reference bounds,
and 8 MiB certificates (MiB = 1048576 bytes). Evidence traversal is charged before
native checking; namespace records retain their own independent size ceiling.

Installed commitments cover this contract, the native harness, common primitives,
namespace, receipt, certificate and evidence machinery, and this specification.
Changed dependencies invalidate selected policies. Public replay uses
`vstd current-object check` with explicit version, objective, represented kind,
request and policy. Actual execution, authentic observation, complete kind/tier
coverage, authority, public checkability and polished issuance remain unestablished.
