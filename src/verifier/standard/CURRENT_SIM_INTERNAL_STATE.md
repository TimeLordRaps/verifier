# Current simulation internal-state enumeration

Verifier Standard (VSTD) registers `SIM-2.3` as one bounded obligation for a
generative simulation (SIM). It depends on an externally selected `SIM-2.1`
certificate that replays the exact retained finite trajectory. This is a
current-object route; a legacy route with similar spelling supplies no result.

## Selected proposition

Given the exact passing child trajectory and an externally selected declaration
of a complete finite observation-channel inventory, enumerate each
changed state key that changes no channel output under every endpoint hybrid
of the other changed keys in that transition. An endpoint hybrid gives each
other changed key either its retained before or after value; unchanged keys
retain their value. Every channel expression is executed by the bounded
installed interpreter. This avoids declaring a key hidden merely because a
simultaneous visible change masked a particular attribution order.

The request binds the SIM subject and composition, exact child certificate,
observation artifact, expected hidden-change enumeration, evidence bytes,
mechanism, policy and finite limits. A mismatched complete enumeration,
selected digest contradiction, false child or invalid channel expression is
`FAIL`. Missing selected evidence, an unknown child or exhausted evaluation
bound is `UNKNOWN`. A carried success word is never enough: replay evaluates
the child and observation expressions again. A changed byte or policy pin
invalidates the exact certificate.

The selected model's state values and channel outputs use its declared units;
step and operation counts are dimensionless. Transport limits count bytes.
Secure Hash Algorithm 256-bit (SHA-256) commitments rely on collision
resistance and canonical JavaScript Object Notation (JSON) serialization.
The finite checker admits at most 12 changed state dimensions per transition;
a larger endpoint cube remains `UNKNOWN` rather than being sampled.
It evaluates each selected channel projection once per endpoint hybrid and
reuses that exact projection across state-key comparisons. Both projection
evaluation and comparisons consume the selected operation budget; caching
does not sample or omit endpoint hybrids.
An observation expression undefined on a formal endpoint hybrid also remains
`UNKNOWN`; one undefined on a retained state is `FAIL`.

`declared_complete` means the selected channel list claims to be the model's
whole channel inventory. The external selector's authority to make that claim
is not established here. It does not establish that the model captures every
physical sensor, observer or information path. A hidden result is relative to
the selected finite model and retained transitions; it is not a privacy
guarantee, a claim about unselected trajectories, a whole SIM dynamics-tier
certificate, collector authenticity, consent, governance, security or
publication authority. Physical observation truth remains `NOT_ESTABLISHED`.
